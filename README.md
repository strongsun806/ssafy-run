## 📖 시놉시스 (Story)

> **"오전 8시 50분, 역삼역 3번 출구... 출석 체크 마감까지 남은 시간은 단 10분!**  
> **1층 엘리베이터 앞은 이미 인산인해, 비상계단 문은 저 멀리 보인다.**  
> **쏟아지는 컴파일 에러와 머지 컨플릭트를 뚫고, 30개의 험난한 과제를 클리어하여 9시 입실 체크 QR을 찍어라!"**

**SSAFY RUN: CYBER SPRINT**는 SSAFY(삼성청년SW아카데미) 교육생들의 치열한 일상과 알고리즘 도전 과제들을 스타일리시한 신스웨이브 네온 아트워크, 쾌감 넘치는 팬텀 잔상 이펙트, RPG 스펙 성장 시스템, 그리고 긴장감 넘치는 30단계 스테이지 캠페인으로 구현한 오리지널 웹 하이퍼 러닝 액션 게임입니다.

## 🌟 핵심 게임 모드 및 최신 시스템 (v1.6.0)

### 1. ✨ 하이엔드 사이버펑크 그래픽 & 직관적인 클린 UI
스팀(Steam) 인디 액션 게임 감성의 독창적인 프로시저럴 아트워크와 정밀한 인터페이스를 탑재했습니다:
- **네온 에너지 스카프 & 호버 제트팩**: 캐릭터의 주행 프레임과 점프/슬라이드 물리 상태에 맞춰 실시간 파동으로 휘날리는 사이버 머플러와 추진기 불꽃 연출
- **사이버 팬텀 잔상 (Phantom Afterimage) & 쇼크웨이브**: 2단 점프, 슬라이드, 하이퍼 대시 시 장착한 스킨의 고유 네온 컬러 잔상과 360도 파동 링 생성
- **정교한 히트박스 & 완벽한 뒤로가기 내비게이션**: 모든 화면(`스테이지 선택`, `인게임`, `일시정지`, `클리어/게임오버 모달`)에서 우측 상단 **`[◀ 메인]` 버튼**, **`ESC` / `Backspace` 단축키**, 그리고 **브라우저 뒤로가기 버튼**을 통해 언제든 즉시 메인 로비로 복귀 가능

---

### 2. 🗺️ 택티컬 30단계 하드코어 스테이지 캠페인 (30-Stage Tactical Campaign)
시작 즉시(0.15초) 쏟아지는 장애물 웨이브와 정교한 복합 패턴을 돌파하며 1단계부터 30단계까지 제패하는 하드코어 레벨 디자인 모드입니다:
- **Chapter 1. 테헤란로 출근길 (STAGE 1 ~ 10)**:
  - 빠른 초기 템포와 연속 장애물, 점프 후 공중 급강하 패턴 입문
  - 목표 거리: `300m ~ 600m` | 주행 속도: `480 ~ 635 px/s` | 웨이브 간격: `1,350ms → 990ms`
  - **FINAL BOSS (Stage 10)**: **일타싸피 당구공 보스 출현!**
- **Chapter 2. 비상계단 & 엘리베이터 지옥 (STAGE 11 ~ 20)**:
  - 본격적인 복합 장애물 웨이브, 바닥 낭떠러지 구덩이(최대 48%), 2연속 허들 + 공중 버그 조합
  - 목표 거리: `600m ~ 900m` | 주행 속도: `630 ~ 760 px/s` | 웨이브 간격: `980ms → 780ms`
  - **FINAL BOSS (Stage 20)**: **배틀싸피 중무장 전차 보스 출현!**
- **Chapter 3. 멀캠 11층 미래 코딩 랩실 (STAGE 21 ~ 30)**:
  - 극한의 반사신경과 하이퍼 대시 활용을 요구하는 초고속 스プリント, 고속 비행 버그 미사일 기습
  - 목표 거리: `900m ~ 1,350m` | 최고 속도: `765 ~ 900 px/s` | 웨이브 간격: `760ms → 590ms`
  - **SPECIAL BOSS (Stage 28, 29)**: 일타싸피 & 배틀싸피 연속 습격
  - **FINAL CLEAR (Stage 30)**: **SSAFY 최종 수료식 캠퍼스 도착 관문 돌파!**
- **3대 고난도 복합 장애물 패턴**:
  1. **점프 → 공중 급강하 슬라이드 콤보**: 바닥 모니터를 점프로 넘자마자 공중에서 `↓` 키로 급강하하여 연속 공중 배너 밑으로 슬라이딩 통과
  2. **2연속 지상 허들 + 공중 드론 웨이브**: 정밀한 2단 점프 체공 타이밍을 요구하는 복합 지형
  3. **고속 비행 버그 미사일**: 일반 트랙보다 1.35배 빠르게 날아오는 고도별 버그 미사일 회피

### 3. 🔧 스펙 강화 연구소 (TECH LAB) & ⚡ 초음속 하이퍼 대시 & 🔤 S·S·A·F·Y 피버
고난도 스테이지 돌파를 돕는 RPG 영구 성장 시스템과 액티브 스킬 시스템입니다:
- **스펙 강화 연구소 (Cyber Tech Lab - Lv.1 ~ Lv.10 영구 업그레이드)**:
  - **멘탈 코어 증폭**: 최대 체력(Max HP) `100` → 최대 **`190 HP`** 영구 확장
  - **알고리즘 연산 증폭**: 모든 획득 점수 보너스 `+0%` → 최대 **`+72%`** 추가 증폭
  - **AI 비트 드론 & 방어막 오버클럭**: 출격 시 **육각 플라즈마 에너지 쉴드** 기본 장착 및 주기적으로 전방 장애물을 궤도 레이저로 자동 파괴하거나 쉴드를 재충전 (쿨타임 `16초` → **`7초`** 단축)
  - **일일 무료 연구 보급품**: 연구소 방문 시 매일 **`+600 G`** 무료 수령 지원
- **액티브 스킬 — 초음속 하이퍼 대시 (`[Shift]` / `[E]` / 우측 하단 `DASH` 버튼)**:
  - 쿨타임 `7.5초`마다 발동 가능하며, `1.25초` 동안 **`1.85배속` 초음속 무적 돌진** 상태로 전환되어 부딪히는 모든 장애물을 즉시 격파(`+500점`)합니다.
- **`S·S·A·F·Y` 알파벳 캡슐 수집 & 하이퍼 보너스 타임**:
  - 트랙 위의 `S`, `S`, `A`, `F`, `Y` 다섯 글자 캡슐을 모두 모으면 **`+3,500점` + `+25 G` + `체력 +35 회복` + `플라즈마 쉴드 재충전` + `무적 골든 피버`**가 동시에 폭발합니다!

### 4. 🧩 일타싸피 & 배틀싸피 비주얼 알고리즘 스튜디오 (Visual Logic Studio)
지친 손가락을 잠시 쉬어갈 수 있도록, 스테이지 10(일타싸피), 스테이지 20(배틀싸피) 및 랭킹런 주요 구간 진입 시 **비주얼 노드 기반 알고리즘 코딩 평가 세션**이 열립니다:
- **다채로운 5대 알고리즘 카테고리 분류**:
  - **이벤트 (Events)**: `[실행 버튼을 클릭했을 때]` 시작 트리거(Trigger) 블록으로 알고리즘 개시
  - **동작 (Motion)**: `[조준 각도를 (45°)로 정하기]`, `[벽에 닿으면 튕기기]`, `[앞으로 (2칸) 이동하기]`, `[우측으로 (90°) 회전]`
  - **제어 (Control)**: `[타구 파워를 (80%)로 설정]`, `[0.3초 포탑 안정화 대기]`
  - **출력 및 사운드 (Output & Sound)**: `[큐대로 수구 치기!]`, `[주포 철갑탄 1발 발사!]`, `["대사 말하기" 말풍선 출력]`, `[효과음 재생]`
  - **센서 감지 (Sensing)**: `[목적구가 포켓에 닿았는가?]`, `[적 보스 탱크 레이더 탐지 락온]`
- **실시간 시뮬레이션 인터랙션 & 클리어 보상**:
  - `[정답 자동조립]` 및 `[즉시 패스]` 편의 버튼 제공
  - 컴파일 성공 시 **멘탈(HP) 100% 완전 회복 + 코인 +30 G + 점수 +5,000점 + 7초간 무적 골든 피버** 발동!

## 🎮 조작법 (Controls)

| 동작 | 데스크톱 키보드 | 모바일 / 마우스 인터페이스 |
| :--- | :--- | :--- |
| **1단 점프 / 2단 점프** | `Space` 또는 `↑` / `W` 키 | **화면 우측 절반** 터치 (또는 `JUMP` 버튼) |
| **슬라이드 (숙이기)** | `↓` 또는 `S` 키 (길게 누르기) | **화면 좌측 절반** 터치 유지 (또는 `SLIDE` 버튼) |
| **공중 급강하 (Fast Fall)** | 공중에서 `↓` 또는 `S` 키 | 공중에서 **화면 좌측** 터치 |
| **초음속 하이퍼 대시** | `Shift` 또는 `E` 키 (쿨타임 7.5초) | 화면 우측 하단 **`DASH [Shift]`** 버튼 클릭 |
| **일시 정지 (PAUSE)** | `P` 키 | 화면 우측 상단 **`II`** 버튼 클릭 |
| **메인 화면 복귀 (뒤로가기)** | `ESC` 또는 `Backspace` 키 | 우측 상단 **`[◀ 메인]`** 버튼 또는 **브라우저 뒤로가기** |
| **사운드 음소거 (Mute)** | 화면 우측 상단 `SND` 버튼 클릭 | 화면 우측 상단 `SND` 버튼 터치 |

## 🛠 기술 스택 (Tech Stack)

```
┌────────────────────────────────────────────────────────┐
│               SSAFY RUN: CYBER SPRINT                  │
└────────────────────────────────────────────────────────┘
          │                                  │
          ▼                                  ▼
┌──────────────────┐               ┌──────────────────┐
│  Client Engine   │               │ Cloud & Storage  │
│ ──────────────── │               │ ──────────────── │
│ • Phaser 3.80+   │               │ • Firebase RTDB  │
│ • TypeScript 5.7 │               │ • LocalStorage   │
│ • Web Audio API  │               │ • GitHub Pages   │
│ • Canvas 2D / GL │               │ • GitHub Actions │
└──────────────────┘               └──────────────────┘
```

- **Game Engine**: [Phaser 3](https://phaser.io/) (2D 캔버스 렌더링, 아케이드 물리 엔진, 씬 매니저)
- **Language**: [TypeScript 5.7](https://www.typescriptlang.org/) (엄격한 타입 안전성 및 상태 관리)
- **Bundler**: [Vite 6.3](https://vitejs.dev/) (초고속 HMR 및 최적화 빌드)
- **Cloud Database**: Google Firebase Realtime Database (전국 실시간 랭킹 REST API 연동)
- **Local Persistence**: Web LocalStorage (스테이지 30단계 진행도, 별점, 스펙 연구소 레벨, 스킨, 코인 영구 저장)
- **Audio Synthesis**: Web Audio API (외부 에셋 로딩 없이 실시간으로 합성되는 8비트 사운드 FX & BGM)
- **Automation / CI**: GitHub Actions (메인 브랜치 푸시 시 자동 배포)
